Win32 API·GDI 기반 1인 프로젝트로 와이어 이동과 전투·애니메이션, 적 AI와 보스 패턴, 맵 에디터를 구현하고 프레임워크를 보강했습니다.

담당 작업​

와이어 이동과 플레이어 액션

그래플·스윙 이동과 처형·폭탄 상호작용을 구현하고 플레이어 상태에 맞춰 애니메이션과 사운드를 연결했습니다.

적 행동과 전투 진행

일반 적 AI와 불새 패턴, 트리거 기반 전투 구간 및 클리어 흐름을 구현했습니다.

맵 편집과 런타임 보강

타일·충돌 영역·객체 배치를 저장하고 불러오는 맵 에디터를 만들고, 스크롤·입력 갱신·화면 밖 렌더 생략과 디버그 패널을 보강했습니다.

에셋 추출과 스프라이트 작업

AssetStudio로 원작 에셋을 추출하고 Aseprite로 스프라이트 작업을 진행해 게임 내 애니메이션과 배치에 사용했습니다.

기술 문서​

  • Foundation1
    • 게임플레이 제작을 위한 프레임워크와 디버그 도구 보강기존 객체 계층을 활용해 스크롤·화면 밖 렌더 생략·입력 갱신을 보강하고 테스트 씬과 런타임 패널을 연결한 과정C++Win32 APIFrameworkDebugging
  • Gameplay8
    • 사슬팔 결속과 스윙·당겨 이동Win32 기반 액션 게임에서 갈고리 발사·충돌 결속·길이 보정과 시간 기반 스윙을 구현하고 천장 이동으로 연결한 과정C++Win32 APIGameplayGrappling Hook
    • 플레이어 이동·액션과 몸체·팔 애니메이션 전환입력의 시작·유지·종료와 지형 충돌을 이동 분기로 연결하고 몸체·팔의 스프라이트 상태를 함께 제어한 Player2 구현C++Win32 APIGameplaySprite Animation
    • 갈고리 포획·처형과 부유 폭탄 공략 연계공통 포획·처형 인터페이스를 일반 적의 사망 처리와 부유 폭탄 발사로 확장하고 플랫폼 파괴부터 화조 격파까지 연결한 구현C++GameplayCombatBoss Mechanic
    • 화조 보스의 공격 패턴과 부위별 애니메이션 제어네 가지 공격을 추적·예고·발동·복귀로 구성하고 독립적인 몸체·날개·무장 스프라이트와 판정 객체를 연결한 Win32 보스전 구현C++Win32 APIBoss AISprite Animation
    • 트리거 기반 전투 구간과 클리어 흐름영역 진입에 따른 적 집단 생성, 주기적인 감시 드론 보충, 도착 지점 판정과 챕터 전환을 연결한 전투 씬 구성C++Win32 APIGameplayTrigger
    • 일반 몬스터 AI와 공격·애니메이션 연동트루퍼의 조준 점사, 디펜더의 유도탄, 워리어의 근접 추적, 감시 드론의 호버링을 개별 행동과 스프라이트 상태로 구성한 과정C++Win32 APIAISprite Animation
    • 플레이어 동작·전투와 사운드 연동FMOD 재생 경로에 행동별 채널과 재생·정지 호출을 연결하고 씬 BGM 및 보스의 반복음을 분리한 과정C++FMODAudioGameplay
    • 인트로·튜토리얼·엔딩 연출과 챕터 진행로고 순차 표시, 월드 조작 안내, 챕터 잠금·해금, 보스 격파 후 마리 엔딩을 하나의 진행 흐름으로 연결한 과정C++Win32 APIUIGame Flow
  • Tools1
    • 맵 편집 도구와 배치 데이터 저장·불러오기타일·충돌 지형·배치 마커를 GUI에서 편집하고 바이너리 파일로 저장해 게임 씬의 실제 객체로 전환한 Win32 맵 제작 도구C++Win32 APIToolsSerialization
