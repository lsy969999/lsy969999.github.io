화조 보스의 공격 패턴과 부위별 애니메이션 제어

공격을 읽고 대응할 수 있는 보스전 구성​

화조 보스를 단순히 플레이어를 추적하며 탄환을 발사하는 적이 아니라, 공격마다 위치·예고·판정·복귀가 달라지는 보스로 구현했다. 폭격, 기관총 타격, 몸통 돌진, 집속탄을 순서대로 연결하고, 공격 시 보이는 무장과 날개 동작을 별도 스프라이트로 제어했다.

상위 패턴은 CObjBossFireBird::State_Update()의 enum·switch로 관리한다. 각 부위의 재생 진행은 자식 객체에 나누고, 경고·탄환·타격·연출 객체는 필요한 시점에 생성한다. 범용 Behavior Tree나 데이터 기반 보스 에디터가 아니라 화조 전용 C++ 구현이다.

폭탄 명중 횟수에 따른 파손·격파는 부유 폭탄 공략 문서에서 설명한다. 여기서는 그 사이에 반복되는 공격 패턴과 시각적 표현에 집중한다.

추적과 네 가지 공격의 반복​

초기 상태는 PLAYER_FOLLOW_START다. 추적을 시작하면 5초 타이머를 등록하고, 추적 중에는 플레이어 주변 반경 100의 회전하는 목표점으로 이동한다. 보스가 플레이어 위치에 계속 겹쳐 붙기보다 주변을 움직이도록 목표 위치를 계산한다.

추적 종료 시 m_iTestCnt % 4로 다음 공격을 결정하고 카운터를 증가시킨다. 이름에 Test가 붙어 있지만 실제 패턴 선택에 사용된다.

Plain Text
추적 → 폭격 → 추적 → 기관총 타격
    → 추적 → 몸통 돌진 → 추적 → 집속탄 → 반복

공격의 선택은 랜덤이나 플레이어 행동 평가가 아니라 고정 순환이다. 아래 시간은 코드의 정상 진행 기준 설정값이며, 프레임 지연·넉백 중단·타이머 실행 시점에 따라 실제 관측 시간에는 차이가 생길 수 있다.

패턴예고·준비공격 수행종료 설정
폭격폭격기 개방 요청, 1초 후 발사 허용플레이어 위쪽을 추적하며 약 0.5초 간격 낙하탄 생성패턴 시작 기준 약 8초
기관총 타격총기 준비 애니메이션과 조준점, 3초 후 타격 허용조준점에 약 0.1초 간격 타격 객체 생성패턴 시작 기준 약 10초
몸통 돌진보스 하강, 3초에 플레이어 위치 저장·경고 생성5초에 저장된 높이로 별도 돌진 객체 생성7초 복귀 시작, 8초 종료
집속탄조준점 추적·보스 하강·배경 헬기 진입4초 조준 고정, 5초 중심 폭발과 자탄 생성8초 복귀 시작, 9초 종료

폭격: 무장 개방과 낙하탄 분리​

폭격 START에서 폭격기 부위에 OPENSTART를 요청하고 1초 타이머로 m_bBombingStart를 켠다. 보스는 플레이어보다 Y가 450 작은 위치 주변을 따라가고, 발사 허용 후 자신의 아래쪽 Y + 150에 CObjBossBullet을 생성한다.

낙하탄은 옵션 1을 사용해 Update마다 Y를 5씩 증가시킨다. 집속탄의 자탄도 같은 클래스를 사용하지만 옵션 0에서는 지정 각도로 이동한다. 출력 스프라이트와 충돌 시 생성할 폭발도 옵션에 따라 달라진다.

폭격 종료 시 무장 닫기 상태를 요청하고 추적으로 복귀한다. 실제 발사 시작은 개방 애니메이션 완료 이벤트가 아니라 별도 1초 타이머다.

기관총: 조준점이 반복 타격을 생성​

기관총 패턴은 총구에서 플레이어까지 탄환을 이동시키지 않는다. CObjBossClusterAim을 플레이어 위치에 생성하고 Set_Shoot(false)로 대기시킨 뒤, 3초 후 true로 바꾼다.

보스는 플레이어 주변을 따라 움직이고 조준점도 플레이어 쪽으로 Update당 3씩 접근한다. 조준점이 발사 상태이면 자신의 위치에 CObjBossShootExplode를 약 100ms 간격으로 생성한다. 이 객체가 타격 스프라이트와 플레이어 피해 판정을 담당하며, 애니메이션 마지막 프레임에서 제거 예약된다.

기관총 부위의 재생과 실제 피해 위치를 분리했다. 피해는 사각형 겹침으로 판정하며 총구와 조준점 사이의 장애물은 검사하지 않는다.

패턴 종료 시 조준점을 제거 예약하고 총기 종료 애니메이션을 요청한다. 조준점 클래스는 집속탄 패턴에서도 재사용되지만 그때는 반복 사격을 켜지 않고 별도 일회성 폭발 함수를 호출한다.

몸통 돌진: 예고 위치를 저장한 뒤 공격​

몸통 돌진에서는 보스가 먼저 아래로 이동한다. 패턴 시작 3초 후 플레이어 위치를 저장하고, 그 높이에 여러 CObjBossBodySlapAlert를 배치한다. 경고마다 20 × index ms의 지연을 주어 순차적으로 나타나게 한다.

5초 시점에는 저장한 위치의 왼쪽에 CObjBossBodySlap을 생성한다. 경고 이후에도 플레이어를 계속 따라가며 돌진선을 수정하는 것이 아니라, 미리 저장한 위치를 공격 기준으로 사용한다.

실제 돌진 객체는 Update당 X를 20씩 증가시키고 플레이어 충돌 시 Damage()를 호출한다. 원래 보스 객체 전체가 동일 경로로 돌진하는 구조가 아니라, 본체의 하강·복귀와 별도 공격 스프라이트·판정 객체로 장면을 구성한다. 종료도 현재는 X가 2000을 넘는 고정 경계로 판단한다.

다만 경고 개수를 계산하는 길이 식에 플레이어의 X와 Y가 섞여 있다. 이 때문에 경고 폭이 의도와 달라질 수 있어, X·Y 좌표를 혼용한 계산을 수정해야 한다.

집속탄: 추적·고정·폭발의 시간차​

집속탄 시작 시 조준점을 생성하고 추적을 켠다. 보스는 아래로 이동하며 1초 후 별도 CObjBossBackHeli가 화면 아래에서 진입한다. 배경 헬기는 연출 객체이고 실제 자탄 생성 위치는 조준점이다.

4초 타이머는 추적 플래그를 끄고, 5초 타이머는 Shoot360ClusterBomblet()을 호출한다. 정상 진행에서는 플레이어가 마지막 조준점 위치를 확인하고 피할 수 있는 약 1초 구간이 생긴다.

해당 함수는 조준점 중심에 폭발 객체 하나와 옵션 0 자탄 15개를 생성한다. 이름은 360이지만 15개를 등간격으로 배치하는 것이 아니라 각각 rand()를 각도로 전달한다. 무작위 방향의 방사이며 균일한 간격을 보장하지 않는다.

폭발 후 조준점을 제거 예약하고 배경 헬기를 퇴장시킨다. 8초에 헬기를 제거 예약하며 보스 복귀를 시작하고 9초에 추적으로 돌아간다. 예고·조준 고정·폭발·퇴장을 각각 타이머 콜백으로 나눈 구성이다.

보스를 부위별 스프라이트로 구성​

보스는 네 부위를 별도로 생성하고 자신을 부모로 지정해 OBJ_MONSTER에 등록한다.

부위초기 로컬 위치제어 내용
CObjBossFireBirdBomber(0, 120)개방 → 열린 상태 유지 → 닫기
CObjBossFireBirdWing(0, -40)중립·상향·하향과 사이 전환, 파손 상태의 클립 선택
CObjBossFirebirdBody(0, 0)정상·파손 몸체 클립 선택
CObjBossFireBirdGun(-2, -30)준비 시작 → 준비 루프 → 사격 루프 → 종료

부모는 m_eAniStateBomber, m_eAniStateGun, m_eAniStateWing, m_eAniStateBroken을 갖는다. 부위 Update는 부모 상태를 읽어 자신의 클립을 선택하고, 마지막 프레임에 도달하면 부모의 진행 상태를 다음 단계로 변경한다. Late_Update의 Motion_Change()에서는 클립이 바뀐 경우 프레임 정보를 초기화한다.

예를 들어 기관총은 START·ING·END를 거쳐 준비와 사격을 이어가고, 날개는 중립에서 상향 유지 상태로 바로 바꾸지 않고 전환 클립을 거친다. 반대 방향으로 바뀔 때도 기존 유지 상태에서 중립 복귀 클립을 요청한다.

날개 방향 요청은 보스의 Move()가 받은 각도 범위로 결정한다. 현재는 -360 < angle < -180을 상향 분기로 사용하는 형태여서, 같은 방향이라도 각도 표기가 다르면 같은 결과를 보장하지 않는다. 예를 들어 다른 경로에서 사용하는 양수 90도도 이 분기에서는 별도로 정규화하지 않는다.

몸체·날개·무장의 애니메이션을 따로 재생하고 상태에 맞춰 조합했다.

시간 제어와 공격 중단의 경계​

Set_Timer()는 작업을 시간 매니저에 저장하고, 메인 갱신에서 시간이 지나면 콜백을 실행한 뒤 제거한다. 별도 스레드나 비동기 작업이 아니라 프레임 루프 안의 지연 실행이다. Delay()는 패턴 Update에서 직접 검사하며 호출 후 기준 시간을 현재 Tick으로 바꾼다. 지연된 횟수를 모두 따라잡아 반복 실행하지는 않는다.

폭탄에 맞아 넉백 중이면 보스의 일반 State_Update()가 건너뛰어진다. 하지만 시간 매니저의 예약 콜백은 계속 갱신되고, 이미 생성한 조준점·탄환 역시 별도 객체로 동작한다. 보스 패턴 분기의 일시 중단이 모든 공격·타이머의 취소를 뜻하지는 않는다.

보스는 현재 타이머 ID를 보관해 패턴 종료나 Release()에서 취소하지 않는다. 콜백은 this와 m_pClusterAim에 접근하므로, 패턴 교체·객체 제거·씬 이동이 겹칠 때 이미 유효하지 않은 대상을 참조할 가능성을 점검해야 한다.

구현 결과​

핵심은 서로 다른 네 공격을 단순 발사 간격 차이가 아니라 이동·예고·조준 고정·타격 위치·퇴장 방식으로 구분한 것이다. 별도 부위 애니메이션과 공격 객체를 연결해 공격 전 준비와 실제 위험 구간을 다르게 표현했다.
