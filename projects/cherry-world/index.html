C*erry의 C*erry Walk 걷기 기능을 기반으로 한 신규 앱에서 iOS 개발과 웹·네이티브·서버 연계를 담당했습니다.

프로젝트 개요​

C*erry의 C*erry Walk 걷기 기능에서 출발한 신규 앱입니다. 웹과 네이티브 기능을 연결해 걸음·보상과 광고를 제공하며, 앱 출시 이후 계정 이전과 서비스 운영을 이어 갔습니다.

담당 작업​

iOS 앱과 광고 연계

iOS 앱 개발을 전담하고 Android·iOS 광고 SDK·오퍼월 연계와 광고 공통 계층 설계를 수행했습니다.

웹–네이티브 통신과 걸음 정책

C*erry Walk에서 시작된 콜백·Promise 기반 통신 방식과 설명 자료를 정리하고, 다계정·다앱·초기화 상황의 걸음·보상 정책 변경안을 검토했습니다.

로그인 이전 장애 대응

변경 전후 사용자 식별정보를 매핑하고 LDAP·RDB 갱신 과정의 SQL 오류와 계정 중복을 추적했습니다.

기존 타이머의 자원 누적 추적

주간 재시작으로 가려졌던 타이머별 스레드 풀 누적과 자원 고갈을 대용량 배치 이후 로그·덤프와 연결해 분석했습니다.

TypeScript 도입과 개발 환경

기존 JavaScript와 공존하는 TypeScript를 도입·사용하고 빌드·디버깅 방법을 안내했습니다.

연휴 운영 중 SQL 오류 추적

추석 모니터링에서 발견한 MyBatis 사용 쿼리의 공백·줄바꿈과 DB 실행 SQL 파싱 문제를 추적하고 오류 로그를 남겼습니다.
