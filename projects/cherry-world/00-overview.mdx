# C\*erry World 신규 앱과 서비스 연계

## 개요 {/* #article-introduction */}

C\*erry World는 기존 C\*erry의 걷기 기능인 C\*erry Walk를 기반으로 만들어진 서비스다. 이\*넷의 C\*erry 부서에서 분사한 주식회사 C\*erry에서 신규 앱 출시와 유지보수에 참여했으며, iOS 개발을 전담하고 Android·iOS 광고 연계를 담당했다.

| 항목 | 내용 |
| --- | --- |
| 경력 구간 | 2022.12 – 2023.12, 주식회사 C\*erry |
| 개발 배경 | C\*erry의 C\*erry Walk 걷기 기능을 기반으로 신규 서비스 전개 |
| 담당 범위 | iOS 개발, 웹·앱 통신, Android·iOS 광고 연계, 서비스 유지보수 |
| 주요 기술 | Swift, Android, JavaScript, TypeScript, webpack, WebView, Spring Boot, PostgreSQL |
| 주요 대응 | 걸음·보상 정책 검토 및 개선 작업, Apple 로그인 마이그레이션 |

기간은 프로젝트를 정리하기 위한 경력 구간이다. 기능별 최초 개발일과 실제 배포일은 서로 다르며, C\*erry Walk에서 시작된 공통 작업을 전부 이 기간에 처음 만든 것으로 소개하지 않는다.

## 추천 문서 {/* #먼저-읽을-대표-사례 */}

### 1. Apple 로그인 마이그레이션과 장애 대응

계정 이전 후 기존 사용자가 신규 가입으로 이어지는 문제에 대응했다. 변경 전후 식별정보를 매핑하고 LDAP·RDB 갱신 중 발생한 SQL 오류와 계정 중복을 추적했다.

[대상 선정·갱신·재처리 과정 읽기](/projects/cherry-world/apple-login-migration)

서로 다른 저장소와 로그인 진입점을 함께 살펴야 했던 사례다. 매핑 성공 건수와 최종 로그인 성공은 구분하며, 초기 이전 과정에서 놓친 조건과 대응도 함께 설명한다.

### 2. 대용량 배치로 드러난 스레드 풀 누적 분석

주간 Pod 재시작 중에는 드러나지 않던 문제가 C\*erry World의 대용량 배치에서 나타났다. 로그·덤프를 타이머별 풀 생성과 종료 누락에 연결해 원인을 분석했다.

[증상 완화에서 자원 수명 분석까지 읽기](/projects/cherry-world/native-thread-exhaustion)

기존 서비스의 자원 누적을 추적한 경험이다. 최종 수정 코드와 장시간 재검증 자료는 확인되지 않아, 완전 해결 실적이 아닌 원인 분석 사례로 소개한다.

## 앱 이전 작업의 실제 기록

2023년 1월 「앱 이전기」에는 분사에 따라 기존 C\*erry 앱의 개발자 계정을 이전한 과정도 남겼다. 이는 신규 C\*erry World 앱을 이전했다는 뜻이 아니라, 같은 시기의 기존 앱 운영·이전 업무다. 계정 이전과 외부 연계 기능 점검이 이어지는 맥락을 보여 주는 자료로 함께 정리한다.

[![Google Play 앱 이전 완료를 안내한 2023년 1월 6일 메일](/img/work-evidence/android-app-transfer-complete.png)](/img/work-evidence/android-app-transfer-complete.png)

*당시 보관한 Google Play의 이전 완료 안내.* 수신·참조 계정과 문의 식별번호를 가렸다. 완료 안내에도 연결된 개발자 프로젝트와 광고 SDK를 별도로 확인하라는 내용이 있다. 이 메일만으로 모든 연계 기능의 검증까지 끝났다고 해석하지 않는다.

Apple 쪽은 앱 이전 이후 로그인 식별정보 문제가 발생했다. [Apple 로그인 마이그레이션 문서](/projects/cherry-world/apple-login-migration)에서 이전 화면과 실제 장애 대응을 나누어 설명한다. 이 기록은 당시 작업 증빙이며 현재 스토어 이전 절차 안내가 아니다.

## 프로젝트 간 경계

iOS 개발을 전담하고 Android·iOS 광고 연계를 담당했으며, 동료와 화면·서버 변경을 조율했다. 두 플랫폼과 공통 백엔드 전체를 단독 개발한 프로젝트는 아니다.

서비스의 출발점은 [C\*erry Walk 배경](/projects/cherry/cherry-work-origin), 같은 회사 재직 중 수행한 [C\*erry Run DB 개선](/projects/cherry/postgresql-query-plan)과 [팀 공통 정기 배포](/projects/cherry/release-branch-management)는 C\*erry 문서에서 다룬다.

## 작성 근거와 확인 범위 {/* #작성-근거 */}

당시 Native–JS 설명 자료, 2023년 5월 걸음 정책 자료, 2023년 1월 Apple 로그인 이전 기록과 처리 결과, 광고 연계 노트를 바탕으로 작성했다. Apple 로그인 마이그레이션의 프로젝트 귀속과 C\*erry Walk의 기원은 담당자 회고를 반영했다. 원본 계정·로그·사용자 데이터는 공개하지 않는다.
