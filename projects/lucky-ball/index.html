Lucky Ball

기간
2024.10 – 2025.01
역할
게임플레이 · 물리 · UI · 플랫폼 연계
참여 인원
1명
플랫폼
Desktop · Android · iOS · Web

Rust와 Bevy 엔진으로 구현한 게임을 Android·iOS·Web 환경과 FFI로 연결한 크로스 플랫폼 개발 경험을 정리합니다.

기술 문서​

  • Foundation1
    • Bevy ECS 기반 추첨 시뮬레이터와 공통 앱 구조3D 물리 추첨 장치를 Plugin·Component·Resource·Event로 구성하고 플랫폼별 진입점에서 공통 앱을 재사용한 구조RustBevyECSArchitecture
  • Gameplay1
    • Rapier 기반 공 혼합·포착·배출과 추첨 단계 제어glTF 장치에 물리 역할을 부착하고 센서·Tween 완료·재혼합 타이머로 추첨을 진행한 구현RustBevyPhysicsGameplay
  • UI & Data1
    • 추첨 규칙 편집과 결과 저장·목록 UIBevy UI 이벤트로 프리셋과 사용자 규칙을 게임에 적용하고 JSON 기록을 최신순 페이지 목록으로 보여주는 구조RustBevyUIPersistence
  • Platform2
    • Android·iOS·Web FFI와 플랫폼별 저장소 연결공통 Rust API 뒤에 JNI·Swift C ABI·wasm-bindgen 구현을 두고 저장·시간·locale·콜백을 연결한 구조와 소유권 경계RustFFIAndroidiOSWebAssembly
    • 플랫폼별 빌드·패키징과 Web 배포Android 공유 라이브러리·iOS 정적 라이브러리·WASM 산출물과 에셋을 각 실행 환경으로 연결하고 GitHub Pages에 게시하는 구성RustBuildWebAssemblyCI-CD
