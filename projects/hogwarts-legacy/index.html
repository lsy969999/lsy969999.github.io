C++20·DirectX 11 기반 7인 팀 프로젝트에서 팀장을 맡아 프레임워크와 물리 시스템을 구성하고, 망토 시뮬레이션·물리 콘텐츠·디버그 도구를 구현했습니다.

프로젝트 개요​

호그와트 레거시를 모작한 3D 액션 RPG입니다. C++20·DirectX 11 자체 엔진 위에 전투와 월드 콘텐츠를 구성하고, PhysX·NvCloth를 이용한 물리 상호작용과 망토 시뮬레이션을 연결했습니다.

담당 작업​

객체 생명주기 안정화

8-byte Generation Handle, FrameEnd 지연 파괴와 Fixed Update 기반 프레임워크를 구성하고, 삭제·슬롯 재사용 이후의 외부 참조를 검증했습니다.

물리 시스템 통합

PhysX 5.6.1의 Rigid Body, CCT, Query, Collision Filter, Joint, Ragdoll을 컴포넌트와 Manager API로 구성했습니다.

물리 시뮬레이션 콘텐츠

NvCloth 망토, Physics Door, 물리 Prop, Summoner’s Court를 실제 게임 흐름과 연결했습니다.

진단과 저작 환경

Tracy 계측과 ImGui 기반 디버그·저작 도구를 마련해 런타임 상태와 병목을 추적했습니다.

협업​

  • Player·AI 담당자가 사용할 수 있도록 CCT, 충돌 Callback, Query API를 제공
  • Animation·Renderer와 Ragdoll Bone, 망토 Simulation, Shadow 적용 순서를 연동
  • Effect·Sound·UI를 물리 콘텐츠와 연결하고 통합 브랜치에서 충돌과 수명 문제를 검증
