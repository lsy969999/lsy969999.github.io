# C\*erry Walk의 시작과 C\*erry World로의 확장

## 개요 {/* #article-introduction */}

C\*erry Walk는 C\*erry에서 시작된 걷기 기능이다. 이후 그 걷기 기능을 바탕으로 C\*erry World가 만들어졌다.

## 서비스와 기능의 관계

| 구분 | 역할 |
| --- | --- |
| C\*erry | 기존 기부 플랫폼 |
| C\*erry Walk | C\*erry 안에서 시작한 걷기 기능 |
| C\*erry World | C\*erry Walk의 걷기 기능을 기반으로 만들어진 서비스 |

C\*erry에서 사용하던 걷기 기능을 고도화해 신규 서비스의 기반으로 활용했다.

## 걷기 기능이 만든 플랫폼 간 요구사항

걸음 수를 화면에 표시하고 보상과 연결하려면 웹 화면만으로 모든 처리를 끝낼 수 없었다. 네이티브가 읽는 걸음 정보, 웹에서 표현하는 상태, 서버가 관리하는 보상 사이의 연결이 필요했다.

C\*erry Walk에서 콜백 이름을 문자열로 넘기는 호출이 반복되면서 흐름을 읽기 어려워졌다. 이 문제를 바탕으로 Native–JS 브리지 개선안을 만들었다. 상세 설계는 [C\*erry World의 브리지 문서](/projects/cherry-world/native-js-bridge)에 정리했다.

## 관련 문서 {/* #이후의-기술-문서 */}

후속 브리지 설계와 2023년 걸음 정책 검토는 C\*erry World 문서에 모았다. 초기 기능의 출시와 이후 변경안을 구분하며, 세부 설계와 적용 범위는 각 문서에서 설명한다.

- [Native–JS 비동기 브리지 개선](/projects/cherry-world/native-js-bridge): 반복되는 웹·앱 호출 흐름의 정리.
- [걸음 수와 보상 정책의 책임 분리](/projects/cherry-world/step-reward-policy): 기존 동기화 방식의 문제와 변경안.
- [C\*erry World 개요](/projects/cherry-world/overview): 신규 앱과 서비스 유지보수에서 맡은 역할.
