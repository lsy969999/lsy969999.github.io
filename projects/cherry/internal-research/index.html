사내 연구 프로젝트와 기술 지식 공유

개요​

사내 연구 프로젝트로 Flutter와 Firebase를 연결해 데이터를 읽고 쓰고 사진을 저장하는 앱을 만들었다. 서비스 기능 개발과 별개로 새로운 기술을 작은 앱에서 다뤄 보고 관련 지식을 공유한 경험이다.

정규 교육과정이 아닌 사내 연구와 기술 공유 활동이었다.

Flutter·Firebase 앱 연구​

Flutter의 pub 패키지를 이용해 Firebase와 연결하고 데이터 읽기·쓰기와 사진 저장 기능을 구현하는 내용을 다뤘다. 화면만 만드는 예제를 넘어 외부 데이터 연동을 포함한 작은 앱으로 기술을 살펴본 프로젝트였다.

연구 내용다룬 범위
Flutter 앱 구성앱에서 동작하는 기능 구현
패키지 연결pub 패키지를 이용한 Firebase 연동
데이터 처리데이터 읽기·쓰기
사진 처리사진 저장 기능

Flutter·Firebase를 익히기 위한 연구용 앱이며, 실제 서비스로 출시하거나 기존 앱을 전환한 작업은 아니다.

함께 진행한 기술 학습과 공유​

JWT, JPA·QueryDSL, ORM과 N+1을 공부하고 팀에 공유했다. JPA와 QueryDSL은 사내 연구 주제로 다뤘다.

ORM 개념에 대한 학습은 이후 NestJS를 공부하며 Prisma를 이해하는 데에도 도움이 됐다. 이는 기술 간 개념을 연결한 학습 경험이지, C*erry 서비스를 NestJS·Prisma로 개발했다는 의미는 아니다.

운영 DB의 조회 병목을 분석한 작업은 C*erry Run PostgreSQL 실행계획 개선에 정리했다.

서비스 구현·업무 전달과의 구분​

새 기술을 작은 예제로 실습하고, 동료가 따라 해 볼 수 있도록 학습 내용을 공유했다.

광고 공통 계층 설계·SDK 연계에서 Android 인턴 개발자에게 업무를 전달한 경험은 실제 기능 개발 과정의 협업이다. 사내 연구 프로젝트와 해당 업무 전달은 별도로 구분한다.
