기부 플랫폼의 사용자·관리자 기능, 외부 회사 연계 후원 페이지와 시즌별 이벤트 업무를 수행했습니다.

프로젝트 개요​

이*넷의 스타트업 부서에서 개발한 Spring Boot·PostgreSQL 기반 기부 플랫폼입니다. 사용자 캠페인과 관리자 기능, 외부 후원 페이지 및 시즌별 C*erry Run 챌린지를 운영했으며, C*erry Walk 걷기 기능은 이후 C*erry World의 기반이 됐습니다.

담당 작업​

사용자·관리자 기능과 화면 공통화

캠페인·행사 페이지와 관리자 기능을 개발하고, Thymeleaf·레이아웃으로 검색 조건과 데이터 테이블을 공통화했습니다.

외부 후원 페이지와 시즌 이벤트

외부 회사와 연계한 소울 후원 페이지를 개발하고 C*erry Run 챌린지 인수인계와 C*erry Walk 관련 업무를 수행했습니다.

가입 스파이크의 DB 병목 분석

2023년 C*erry Run 가입 급증 때 사용자 조회의 풀스캔을 분석하고 일반·표현식 인덱스를 추가해 실행계획 변경을 확인했습니다. 가입자 집중 시 AWS의 DB 부하·대기 이벤트도 기록했습니다.

정기 배포와 브랜치 이주

팀 공통 주간 정기 배포를 전담하고 C*erry 개발 중 master 브랜치 이주 계획을 작성했습니다.
