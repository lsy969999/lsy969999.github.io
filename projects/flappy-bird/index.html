Rust·Bevy·Avian2D로 입력·충돌·득점과 결과 화면을 구현하고, FFI로 최고 점수 저장을 모바일·Web 환경에 연결한 1인 Flappy Bird 클론 프로젝트입니다.

프로젝트 개요​

Rust·Bevy·Avian2D로 한 판의 입력·물리·득점·결과 화면을 구성한 Flappy Bird 클론입니다. 공통 게임 코드를 모바일·Web 실행 환경과 연결했습니다. 초기 개발은 2024.08.23~09.01에 진행했고, GitHub Pages 배포는 2025년에 별도로 보강했습니다.

담당 작업​

입력에서 한 판 종료까지

Avian2D 기반 물리 상승·충돌·센서 득점과 파이프 재사용을 구현하고, 일시정지·결과 전환을 상태별 시스템 실행과 이벤트로 연결했습니다.

단계적인 결과 피드백

기준 해상도와 마스크로 화면 비율을 유지하고, Tween·Atlas와 Timer로 플래시·패널 이동·점수 카운트·메달 표시를 구성했습니다.

공통 코드와 플랫폼 경계

JNI·Swift C ABI·wasm-bindgen으로 공통 최고 점수 저장 API를 플랫폼별 저장소에 연결하고, 외부 콜백을 채널로 Bevy 갱신 흐름에 전달했습니다.

실행 결과물 전달

모바일 호스트에 Rust 라이브러리와 에셋을 전달하고, Web 빌드부터 Pages 게시까지 workflow로 연결했습니다.
